# Arsenal analytics

Arsenal analytics is a personal, read-only script used by the owner of the YouTube channel "Орудие древности" to read that channel's own statistics (views, watch time, impressions, click-through rate, subscribers) through the YouTube Data API, YouTube Analytics API and YouTube Reporting API.

The app is used only by the channel owner. It does not upload, edit or delete anything on YouTube and is not offered to other users.
