# Privacy policy — Arsenal analytics

Last updated: 28 September 2026.

Arsenal analytics is a personal script run by the owner of the YouTube channel "Орудие древности" on their own computer. It is not a public service and has no users other than the channel owner.

## What data is accessed

With the owner's consent through Google OAuth, the script reads, in read-only mode (scopes youtube.readonly and yt-analytics.readonly), statistics of the owner's own YouTube channel: videos and their public details, views, watch time, audience retention, traffic sources, subscribers gained, thumbnail impressions and click-through rate.

## How the data is used

The data is used only to analyse the performance of the owner's own channel and plan future videos. The script never uploads, edits or deletes anything on YouTube.

## Storage and sharing

Data and the OAuth token are stored only locally on the owner's computer. They are not sold, shared with or transferred to any third party, and are not used for advertising.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Locally stored data can be deleted by the owner at any time.

## Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
